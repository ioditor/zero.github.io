# Font rights / Права на шрифты

Source: user attachment TTF.zip from the referenced Zero conversation. It contains only Flow-Regular.ttf, Still-Regular.ttf and Mono-Regular.ttf; no LICENSE.txt.

On 18 October 2026 the user explicitly confirmed rights for all three fonts in response to a question covering conversion to WOFF2 and hosting in the website for specimen display. This confirmation is the basis for including these WOFF2 resources. It is not a declaration of a general open-source font license.

Still and Mono name records mention permission to use, modify and redistribute, but refer to an absent LICENSE.txt. Flow records state original outlines prepared for the project owner, with no explicit license text. All three have OS/2 fsType=0; this technical flag alone was not treated as proof of rights.

TTF files are excluded from the deliverable. WOFF2 resources are local display assets; there are no font download links. Like any webfont, they are necessarily fetched by browsers. Original name/copyright records are retained in the converted fonts. Source and output SHA-256 values and exact name records appear in font-manifest.json. Conversion: fontTools 4.67.0, Brotli 1.2.0, no subsetting or outline editing.
