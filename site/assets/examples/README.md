# Website Examples / Примеры для сайта

Seven editable compositions, each with Russian and English pages. Open the .zero files in Zero; text, pen strokes and spatial letters remain editable. PDFs and page PNGs are viewing previews only.

Семь редактируемых композиций, по две страницы: RU, EN. В .zero сохранены тексты, ручные штрихи и пространственные буквы. PDF и PNG предназначены для просмотра.

1. Poster — The slow hour / Час без спешки
2. Type Landscape — Letters at low tide / Буквы во время отлива
3. Pen Landscape — The road to the hills / Дорога к холмам
4. Mind Map — A garden for everyone / Сад для всех
5. Hand-Drawn Table — Dinner in the garden / Ужин в саду
6. Diagram — The city wakes / Город просыпается
7. Story Showcase — The window that stayed lit / Окно, где горел свет (Still title, Flow subtitle and closing lines, Noto Sans story, Mono labels)

The tide study derives from the editable Type Landscape with a new text frame and water inclination; all other website compositions were authored separately. Diagram values are illustrative.

Website-Examples is distributed separately and is excluded from the application gallery and Windows portable package. Artworks may be used to illustrate the Zero website. Font notices are supplied in the source package (third_party).
